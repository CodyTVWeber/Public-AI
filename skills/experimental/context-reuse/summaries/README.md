# Session summaries

Dated docs ([docs-current-or-dated](../../../../rules/docs-current-or-dated.md)): `YYYY-MM-DD-short-title.md`.

First 10 lines include `Date: YYYY-MM-DD`. Optional: `Supersedes: <path>`.

| Section | Holds |
|---|---|
| Goal | What the session aimed to do |
| Decisions | Architecture or process calls |
| Open items | Follow-ups |
| Facts and locations | Code paths, constraints |
| Related | Files or earlier summaries |

Immutable after write except typos. Correction → a dated file with `Supersedes:`. Aim 300–800 tokens. Never dump transcripts.

Read 1–2 relevant files after `STATE.md`. Optional `INDEX.md` (Current) lists them when the folder is large.
