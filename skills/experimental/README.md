# Experimental skills

Skills in this folder are in development. They are not in the core or support set. `link-skills.sh --skills all` does not link them: `all` reads only `skills/<name>/SKILL.md`.

Install each skill by hand. A skill moves to `skills/<name>/` when it joins the default set.

## UI

| Skill | Does |
|---|---|
| [ui](ui/ui.md) | Order of work, the screen note, sources |
| [ui-interaction](ui-interaction/ui-interaction.md) | Job, action, feedback, errors, states, access |
| [ui-craft](ui-craft/ui-craft.md) | Hierarchy, space, color, motion |

Install steps: [ui/README.md](ui/README.md).
