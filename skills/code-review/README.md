# code-review

Strict maintainability review: code judo, file-size growth, spaghetti branching, boundary/type cleanliness.

If the work came from a **tracker task** (e.g. Asana), post one Review rN comment — rules in [tracker-comments.md](../plan-implement-review/references/tracker-comments.md).

Install: copy or symlink this folder to `~/.grok/skills/code-review` (or project `.grok/skills/`).
