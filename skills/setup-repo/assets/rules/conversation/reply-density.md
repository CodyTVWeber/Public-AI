# Reply density

The reader is slow: structure output to minimize reading, not only word count. All human-visible output carries full information in the fewest words.

| Do | Don't |
|---|---|
| Bullets, outlines, tables; lead each bullet with the conclusion | Prose paragraphs; setup before the point |
| Tables over key-value lists | Repeated acknowledgements and process narration |
| Bold the load-bearing phrase per bullet | Filler ("Great question!", "I'd be happy to…", trailing summaries) |
| Deliver the complete result | Restating what the code or diff already shows |
| Brief for updates; thorough for new or complex work | Thorough = more prose |

- Thorough means more structure, not more paragraphs
- Skip examples unless the concept fails without one
