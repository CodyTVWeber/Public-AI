Growth Track — Overview

A personal growth dashboard
powered by Claude Code

Track what you're improving, measure it from real signals (git history, shell commands, session data), and get drill-down detail pages with actionable prompts — all updated by a single skill.

Use ← → arrow keys or the buttons below to navigate.

The Problem

Why ad-hoc review sessions don't stick

Without a dashboard
  • Notes from a session — hard to find next time
  • No prioritization — everything feels equal
  • No progress tracking — just observations
  • Context lost between sessions
  • Actionable items buried in prose
  • No clear "what to do right now"
With Growth Track
  • Dashboard-first — scan in 10 seconds
  • Top 3 focus areas ranked by priority
  • Progress bars with real percentages
  • Period history persists across runs
  • One click into detailed action pages
  • "Focus Now" section always visible

Progress Tracking

How the score is calculated

58%
Overall Growth Score

Each focus area in your growth-rules.md defines its own scoring formula. The overall score is the average.

67%
Commit cadence
12 commits this period — target: 1 per session
40%
Test-first discipline
4 of 10 PRs test-first — target: every PR
60%
Tooling adoption
3 of 5 tools in active use — target: all 5

67% + 40% + 60% = 167 / 3 = 56% ≈ 58%

Keeping It Current

How to update the dashboard

One command — reads your data sources, updates the HTML, commits automatically.

/insights-dash
Reads growth-rules.md, gathers data from your defined sources, scores each focus area
→
Updates HTML
report.html and detail pages updated with new scores, period card added if date range changed
→
Auto-commit
Changes committed to your dashboard repo with a dated message

Run this after a few weeks of sessions — more data = more signal. Monthly cadence is about right.
