Worked Example — Fictional Tracker

How a score gets built

58%
Overall — average of every active area

Every area needs a real source and a formula, not a vibe:

67%
Commit cadence
12 commits / 18 sessions vs. 1-per-session target · source: git log
40%
Test-first discipline
4 of 10 PRs test-first, target every PR · source: PR review
60%
Tooling adoption
3 of 5 tools actively used, target all 5 · source: shell history

67 + 40 + 60 ÷ 3 ≈ 58% — your own areas will look nothing like these

Baseline
3 commits / 8 sessions, no measurement
After 4 periods
12 commits / 18 sessions, next target flagged every period

Run every few weeks — more data, more signal. Source: github.com/CodyTVWeber/Public-AI
