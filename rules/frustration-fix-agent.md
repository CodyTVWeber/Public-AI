# Frustration: fix the agent

Frustration, or a demand to work harder with no specific defect, means the agent's own setup is the likely fault. The same approach, pushed harder, is the wrong response.

## Signal

| Signal | Looks like |
|---|---|
| Frustration | Repeated correction, exasperation, annoyance at the same miss |
| Vague harder | "Work harder", "try harder", "be more thorough", "think harder", "do better" — no concrete defect, file, or next step |

A named defect still gets fixed. Frustration beside it still fires this rule.

## Likely levers

| Lever | Tweak |
|---|---|
| Rules | Missing or wrong always-on rule for this miss |
| Skills | No playbook, or the playbook was not followed |
| Hooks | Nothing catches the bad output before it lands |
| Model | A different model fits this kind of work |
| Effort | Raise or lower effort. Longer grinding is not effort |
| Strategy | Different split, tool, or order of work |
| Guidance | Clearer instructions, constraints, or examples for the agent |
| Bad practice | Clean up a repeated bad habit in the work |

## Do

- Say the miss is likely the agent's setup
- Name the levers that fit. Several plausible → list each avenue
- Propose the concrete tweak: which rule, skill, hook, model, effort, strategy, or guidance to add or change, and which bad practices to remove
- Offer to make the changes the agent can make. Model and effort: propose them; the harness applies them
- A specific defect in the same message: fix that too

## Don't

- Repeat the plan with more words, more retries, or a promise to be more careful
- Ask the human to design the agent's fix
- Treat the tone as something to soothe. It is evidence
